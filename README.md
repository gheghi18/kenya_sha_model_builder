# Kenya SHA model builder

A static website where people build their own version of the model Kenya's Social Health Authority (SHA) uses to guess household income and set health insurance premiums (2.75% of the guess). They pick up to 15 survey questions, the model retrains in the browser on the 2021 Kenya Continuous Household Survey (KCHS), and they see what it does: a household's bill, accuracy, who pays too much, fairness across groups, and what drives mistakes, compared with a reconstruction of SHA's model.

## Folders

- `docs/`: the website (plain HTML, CSS and JavaScript, no build step)
  - `assets/app.js`: everything the site does, including retraining the OLS models
  - `data/households.csv`, `data/meta.json`: generated by the export script
- `scripts/export_app_data.py`: builds the two data files from the `kenya_analysis` project

## Regenerate the data

The export reads survey data and model results from the `kenya_analysis` project (default `~/kenya_analysis`; set `KENYA_ANALYSIS` to use another path). Rerun it after retraining there (`code/02_train/training_ols.py`):

```bash
python scripts/export_app_data.py
```

## Preview

```bash
python3 -m http.server 8765 --directory docs
```

Then open http://localhost:8765.

## Publish

GitHub → Settings → Pages → deploy from branch `main`, folder `/docs`.

**Note:** `docs/data/households.csv` is household-level survey microdata. Anyone who can open the site can download it, and Pages sites from private repositories are public unless the organisation uses GitHub Enterprise Cloud.
